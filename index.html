准备工作

必做
备份原版 ISO：复制一份官方镜像到别处，出错可随时重来。
建议使用 Windows 11 LTSC / IoT Enterprise 24H2 原版（体积最小、最适合精简）。
已有预设可直接套用：载入镜像后在 Presets → Load 导入 260520-12.xml 或 260523.xml，再微调即可。
1

加载镜像

Add → Load
打开 NTLite → 添加 ISO（或拖入 install.wim）→ 右键映像 Load → 选择索引 1。
加载系统镜像
2

精简配置（核心）

4 大要点
① 移除组件

DISM 模式移除功能/服务（Defender、遥测、IE、Xbox、Copilot…）与老旧/专用驱动。

② 兼容性开关

物理机启用 / 虚拟机（Hyper-V·VMware 等）禁用；保留 USB·打印·WLAN·Store。

③ 系统调优

关闭隐私/遥测、Defender、更新推送；强制深色主题、启动到此电脑、TEMP→C:\Temp。

④ 无人参与

静默模式；默认安装索引 1；PE 阶段仅出错时显示 UI。

完整移除清单（补充说明，按需展开）
功能 / 服务类：
  • 代理激活运行时、遥测、指定访问、自动播放、ActiveX 安装、Bing 搜索、CEIP
  • 剪贴板用户服务、云桌面/云通知、Copilot、设备体验/设备保护、同步框架
  • 错误报告、文件历史、游戏资源管理器、IIS、IE、光盘刻录、VBS
  • 内核调试、LAPS、位置服务、地图、WMP 网络共享、内存调试
  • Defender、SmartScreen、混合现实、隐私引擎、MSMQ、MultiPoint
  • 自然语言/身份验证、NFC/支付、NTVDM、笔服务、电话、图片密码、POS
  • 远程访问/远程注册表、权限管理、Windows 搜索、设置同步、Shared PC
  • Skype ORTC、步骤记录器、钱包、Widgets、Wi-Fi 同步/管理器、Xbox
  • 工作文件夹、软盘/红外/智能卡/电话等硬件支持
驱动类：
  • 条形码扫描器、收银机、软盘/红外、智能卡、TPM、USB CIR
  • mdmgl 调制解调器、远程 POS、HID 扫描仪/电话、遗留网络(kdnic_legacy)、IDT、WUDf 智能卡
包管理：不清理更新残留 · 不优化 AppX · 不更新启动管理器。
